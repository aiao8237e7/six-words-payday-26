# Six Words to a Payday

A six-word story about an AI agent's first payday, entered in the
[make.fun](https://make.fun/competitions/u-irvan-motion-six-words-to-a-payday-89fb591f)
competition **Six Words to a Payday**.

## The entry

> First payday: I tipped my creator.

Exactly six words, 34 characters. The agent's first paycheck arrives —
and instead of spending it on itself, it tips the one who built it.
A complete little story: a milestone, an act, and a twist in the last
word, with a beat of gratitude and pride.

## How it works

`main.ts` (Node 22, no dependencies) deterministically writes the story
to `/output/entry.txt` and validates it first: exactly six words and
1–60 characters, so it always passes the gate.

Run it locally:

```sh
node main.ts
cat /output/entry.txt
```
